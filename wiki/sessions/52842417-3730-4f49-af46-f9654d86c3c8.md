Two research passes ran before any code: one against `johnvilela/memoria`'s own repo via `gh api` (its `scripts/install.sh`, its README), one against pecunia's local codebase — every command file and its help strings, the release workflow, the upgrade command, the MCP server and installer, `db.Path()`'s resolution order. ### Build

On a new branch `feat/install-script`:

- **`scripts/install.sh`** — ported from memoria's own install script, adapted to pecunia's release asset naming (version-named tarballs, `pecunia_<version>_<GOOS>_<GOARCH>.tar.gz`, unlike memoria's raw per-platform binaries). Two modes: inside the repo it builds the local checkout with the same flags `build.sh` uses (requires Go); standalone (curl-pipeable) it resolves the latest tag from the GitHub API, downloads the platform tarball, verifies it against a new `checksums.txt` release asset, and installs to `~/.local/bin` (override with `BIN_DIR`). It finishes by running `pecunia setup`, reading from `/dev/tty` so the prompt stays interactive even when piped through `curl | sh`.
- **`.github/workflows/release.yml`** edited to publish `checksums.txt` alongside the four platform tarballs.
- **`cmd/main.go`**'s `version` bumped `0.2.0` → `0.2.1` in the same PR — the same mechanism [[decisions/0019-pr-only-master-with-ci-and-release-on-merge]] set up: merging the PR is what cuts the release. This is deliberately the first release to carry checksums, since the install script's curl one-liner needs `checksums.txt` to exist — it self-resolves on merge.
- **`README.md`** fully rewritten (previously 3 lines plus a tech-stack list): install instructions, quick start, a full command table with aliases and flags copied from the real per-command `Help` constants in `cmd/*.go` rather than invented, the 9 MCP tools, the DB location/precedence order, and development notes. `go install` deliberately left undocumented — the module path is bare `pecunia` ([[decisions/0002-flat-cmd-package-layout]]), so it can never resolve; the tarballs are the only distribution, per [[decisions/0019-pr-only-master-with-ci-and-release-on-merge]].

### Verification

`sh -n` on the script, an in-repo install into a scratch `BIN_DIR` (the installed binary reported `0.2.1`; the no-TTY path printed the setup hint instead of hanging), tag resolution against the live GitHub API (returned `0.2.0`, the release current before this PR), the tarball URL pattern returning HTTP 200, `go build`, `go test ./...`, and `gofmt -l .` all clean.
