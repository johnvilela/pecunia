## What happened

Bootstrapped the `pecunia` Go CLI end-to-end in one session: hello-world skeleton → pre-commit hook → first commit → full accounts module (schema, store, TUI, tests).

### Go project init

- `go mod init pecunia` — module path plain `pecunia`, no VCS host prefix (swap when the repo is published).
- Initial `cmd/pecunia/main.go` printed "Hello, world!"; later removed when the CLI was restructured to a flat `cmd/` package — see [[decisions/0002-flat-cmd-package-layout]].
- `.editorconfig`: `indent_size = 2` everywhere, `[*.go]` overridden to tabs (gofmt demands tabs).
- `/pecunia` binary entry added to `.gitignore`.

### Pre-commit hook

`.githooks/pre-commit` (gofmt + go vet, zero deps) wired via `core.hooksPath`. Full writeup: [[rules/git-hooks]].

### First commit

`159372d` — `feat: initialize pecunia go cli with gofmt/vet pre-commit hook`, root commit, 8 files, staged via explicit paths (never `git add -A`). Wrote [[rules/commit-messages]] documenting the commitlint convention used for this and every commit since.

### CLI restructuring + setup command

Flattened `cmd/pecunia/` into `cmd/` (binary named via `go build -o pecunia ./cmd`, not via directory layout) — see [[decisions/0002-flat-cmd-package-layout]]. Bare `pecunia` now prints an ASCII banner + help. `pecunia setup` resolves the DB path from `PECUNIA_DB` (or `~/.config/pecunia/` default via `internal/db.Path()`), creates an empty SQLite file (`modernc.org/sqlite`, no cgo) if none exists, alerts and does nothing if one does, and with `--force` renames the existing file to a timestamped `.bak` before creating a fresh one.

### Accounts module

Implemented the full spec from [[tasks/01-accounts-module]]: `internal/db` (embedded numbered migrations, applied on every `Open()`), `internal/accounts` (domain types, store, huh/bubbles TUI), `cmd/accounts.go`. Balance encoding decision: [[decisions/0001-balance-as-int64-minor-units]].

Deps added: `huh`, `bubbles`, `bubbletea`, `lipgloss`, `modernc.org/sqlite`.

Verified end-to-end against a seeded DB — list table, details by code/id, freeze toggle, per-command `-h`, piped output — plus `go vet`/`go test`/`gofmt` all clean. The interactive paths (create form, edit/delete/freeze picker, delete confirm) were **not** exercised headless — under no TTY they fail cleanly (`could not open a new TTY`, exit 1) instead of panicking, but need a real terminal to verify.

No commit was made for the accounts module by the end of the session.
