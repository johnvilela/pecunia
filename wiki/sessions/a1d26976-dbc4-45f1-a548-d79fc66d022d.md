## What happened

Added a `build.sh` script to compile the kakei CLI into a single static, stripped binary, per the user's request: "Create a build script that will build this CLI into a single binary."

- Inspected repo state first: `go.mod`, `AGENTS.md`, `cmd/`/`internal/` layout, `cmd/main.go` header, `.gitignore`, `.githooks/*`.
- Wrote `build.sh` at the repo root (`/home/jv77/Documents/dev/kakei/build.sh`).
- Verified: `chmod +x build.sh && ./build.sh` succeeds; `file kakei` reports statically linked; `ls -lh kakei` shows 8.0M; `./kakei --help` runs and prints output.
- Deferred: version stamping, multi-platform build matrix, Makefile — noted to add when releasing.
